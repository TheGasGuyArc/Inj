# RUNNERS V2

A GitHub Pages-ready prototype for **RUNNERS — The Market Never Sleeps**.

## Upload to GitHub Pages

Keep this exact structure and make sure `index.html` is in the repository root:

```text
runners/
├── index.html
├── assets/
├── css/
└── js/
```

No build command is required. GitHub Pages can deploy directly from the `main` branch and `/ (root)`.

## Current V2 features

- Boot / entry screen
- Interactive city hero
- District cards
- Market chart simulation
- Market event interaction
- Runner XP / level system
- Missions
- RunUp launch terminal
- Demo wallet flow
- Responsive mobile UI

The wallet and market values are intentionally simulated in this prototype. Production Injective wallet/on-chain integration should be added after the visual direction is approved.
